# Escenarios

| Ambientación | Descripción |
| --- | --- |
| Formulario | El formulario que se va a mostrar. Campo obligatorio. Normalmente a través de la lista desplegable; alternativamente, inserta la dirección completa del formulario o la cadena de 24 dígitos al final. |
| Color de acento | Color para el botón de enviar, marcador obligatorio de campo y marcado de selección. MAN por defecto rojo; alternativamente antracita o negro. |
| Densidad | Estándar (40 px de altura de campo) o Compacto (36 px) — para páginas con espacio limitado. |
| Marcador de campo obligatorio | Asterisco (*') o escrito '(requerido)' después de la etiqueta. |

## Añadir a la lista corta

La lista solo muestra formularios para los que tienes **derechos administrativos**. A
forma extranjera que se te permite incrustar no aparece allí; es
aún se puede introducir insertando la dirección.
