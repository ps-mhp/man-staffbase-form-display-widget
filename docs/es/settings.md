# Configuración

| Configuración | Descripción |
| --- | --- |
| Formulario | El formulario que se va a mostrar. Campo obligatorio. Normalmente se selecciona de la lista desplegable; como alternativa, se puede introducir la dirección completa del formulario o la cadena de 24 caracteres que aparece al final de la misma. |
| Color de contraste | Color para el botón de envío, los indicadores de campos obligatorios y las marcas de selección. Por defecto, MAN Rojo; también se puede elegir antracita o negro. |
| Densidad | Estándar (42 px de altura de campo) o Compacta (36 px): para páginas con poco espacio. |
| Indicador de campo obligatorio | Asterisco (`*`) o «(required)» escrito completo detrás de la etiqueta. |

## Acerca de la lista de selección

La lista solo muestra los formularios para los que tienes **derechos de administración**. Por lo tanto, un
formulario ajeno que puedas incrustar no aparecerá allí; no obstante,
se puede añadir introduciendo la dirección.
