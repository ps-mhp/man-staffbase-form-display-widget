# Paso a paso

1. **Crear un formulario** — si aún no lo has hecho: en la
   aplicación de formularios de Staffbase, crea y publica el formulario.
2. **Insertar un widget** — en la página de destino, en el editor del CMS, inserta el bloque
   «FormDisplay».
3. **Seleccionar formulario** — en el cuadro de diálogo de configuración, selecciona el formulario de la
   lista de opciones. Si no aparece allí (por carecer de derechos de administración),
   introduce la dirección del formulario, tal y como aparece en la barra de direcciones, en el campo correspondiente.
4. **Aspecto**: si es necesario, adapta el color de contraste, la densidad y
  el marcado de los campos obligatorios. Los ajustes predeterminados se ajustan a la
  identidad corporativa de MAN.
5. **Publicar**: guarda y publica la página. Para comprobarlo, utiliza la
   página publicada: al pulsar «Enviar», la lógica de «ya respondido»
   se aplica tal y como lo haría en la aplicación de formularios real.
