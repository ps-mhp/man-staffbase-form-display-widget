# Paso a paso

1. **Crear formulario** — si aún no lo has hecho: en el
   Staffbase Forms app, crea y publica el formulario. 
2. **Insertar widget** — en la página de aterrizaje del editor CMS, seleccione el
   "FormDisplay". 
3. **Seleccionar formulario** — en el cuadro de diálogo de configuración, seleccione el formulario desde el
   Selecciona la lista de selección. Si falta ahí (sin derechos administrativos), el
   Forma la dirección desde la barra de direcciones en el campo. 
4. **Apariencia** — color de acento, densidad y
   Ajusta la marcado de campo requerido. La configuración predeterminada corresponde a la
   HOMBRE CI. 
5. **Publicar** — Guardar y publicar la página. Para comprobar la
   Usando la página publicada: Enviar y la lógica de Ya Respondido
   Corre contra la app de forma real.
