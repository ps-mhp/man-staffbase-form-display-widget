# Configurações

| Cenário | Descrição |
| --- | --- |
| Formulário | O formulário a ser exibido. Campo obrigatório. Geralmente via lista suspensa; alternativamente, insira o endereço completo do formulário ou a string de 24 dígitos no final dele. |
| Cor de destaque | Cor para o botão de enviar, marcador de campo obrigatório e seleção de marca. Padrão MAN vermelho; alternativamente, antracito ou preto. |
| Densidade | Padrão (40 px de altura de campo) ou Compacto (36 px) — para páginas com espaço limitado. |
| Marcador de campo obrigatório | Asterisco ('*') ou escrito '(obrigatório)' após o rótulo. |

## Adicionar à lista curta

A lista mostra apenas formulários para os quais você tem **direitos administrativos**. A
forma estrangeira que você pode incorporar não aparece ali; ela
ainda pode ser inserido o endereço.
