# FAQ

**No widget do plugin, um aviso vermelho aparece para "Formulários" — por quê?** 
intenção. O widget do plugin Staffbase incorpora formulários como um iframe com fixo
altura. Desde que esse widget esteja instalado, ele alerta lá e aponta para
em "FormDisplay" — o formulário pertence diretamente à página no CI MAN. 

**O widget diz "O formulário não pôde ser carregado" — por quê?** 
Na maioria dos casos, o formulário não é (ou não mais) publicado ou o ID aponta para um
instalação deletada. abra o formulário no aplicativo Formulários e insira o ID com o
Compare a configuração dos widgets. 

**Os leitores verão "Você já enviou este formulário".** 
Essa é a regra de resposta única do formulário, não o widget. Se
múltiplas respostas são permitidas nas configurações do app Formulários
. 

**Por que meu formulário não aparece na lista suspensa?** 
A lista mostra apenas formulários com direitos administrativos e os mais recentes
mudou 100. Em ambos os casos, inserir o endereço do formulário em
O campo. 

**Todos os tipos de perguntas são suportados?** 
Entrada de texto, texto de parágrafo, data, lista de seleção, seleção única e múltipla
são exibidos nativamente no CI MAN. Um tipo de pergunta desconhecido para o widget
aparece como um campo de texto para que a pergunta permaneça respondível; Upload de arquivos
Atualmente não suporta o widget. 

**Em que idioma a forma aparece?** 
O aplicativo de formulário já fornece as perguntas no idioma do leitor
Pessoa. Os controles do widget (enviar, mensagens de erro) são
Inglês, como no widget de Eventos. 

**A resposta conta para a avaliação normal?** 
Sim. O widget envia para o mesmo aplicativo de formulário; e-mails do destinatário, webhooks e
A lista de respostas se comporta como ao preencher a área do formulário.
