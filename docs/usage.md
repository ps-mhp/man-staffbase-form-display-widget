# Schritt für Schritt

1. **Formular anlegen** — falls noch nicht geschehen: in der
   Staffbase-Formular-App das Formular erstellen und veröffentlichen.
2. **Widget einfügen** — auf der Zielseite im CMS-Editor den Block
   „FormDisplay" einfügen.
3. **Formular wählen** — im Konfigurationsdialog das Formular aus der
   Auswahlliste wählen. Fehlt es dort (keine Verwaltungsrechte), die
   Formular-Adresse aus der Adresszeile in das Feld einfügen.
4. **Erscheinungsbild** — bei Bedarf Akzentfarbe, Dichte und
   Pflichtfeld-Markierung anpassen. Die Voreinstellungen entsprechen dem
   MAN CI.
5. **Veröffentlichen** — Seite speichern und veröffentlichen. Zum Prüfen die
   veröffentlichte Seite verwenden: Absenden und die Schon-beantwortet-Logik
   laufen gegen die echte Formular-App.
