# Étape par étape

1. **Créer un formulaire** — si ce n'est pas déjà fait : dans l'
   application Formulaires de Staffbase, créez et publiez le formulaire.
2. **Insérer un widget** — sur la page de destination, dans l’éditeur CMS, insérez le bloc
   « FormDisplay ». La fenêtre « Sélectionner un formulaire » s’ouvre automatiquement ;
   par la suite, c’est le bouton « Sélectionner un formulaire » dans la
   boîte de dialogue de configuration qui l’ouvrira à nouveau.
3. **Sélectionner le formulaire** — cliquez sur le formulaire dans la liste de gauche ; la fonction de recherche
   située au-dessus facilite la recherche lorsque les formulaires sont nombreux. S'il n'y figure pas (pas de
   droits d'administration, plus ancien que les 100 derniers modifiés),
   saisissez l'adresse du formulaire dans le champ « Saisir l'ID manuellement ».
4. **Mise en page** — si nécessaire, choisissez une couleur d'accentuation, la densité et le marquage des champs obligatoires.
   Les préréglages sont conformes à l’identité visuelle de MAN. Les onglets « Ordinateur de bureau », « Tablette » et
   « Mobile » en haut de la page permettent de vérifier le résultat dans chaque largeur.
5. **Appliquer** — cliquez sur « Appliquer » en haut de la page (⌘/Ctrl + S). Cela enregistre
   dans la boîte de dialogue des paramètres ; l’enregistrement ne se fait qu’en cliquant sur « Enregistrer » dans Studio.
6. **Publier** — enregistrer et publier la page. Pour vérifier,
   utilisez la page publiée : le bouton « Envoyer » et la logique « Déjà répondu »
   fonctionnent avec la véritable application de formulaire.
