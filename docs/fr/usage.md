# Étape par étape

1. **Créer un formulaire** — si ce n’est pas déjà fait : dans l’
  application Formulaires de Staffbase, créez et publiez le formulaire.
2. **Insérer un widget** — sur la page de destination, dans l’éditeur CMS, insérez le bloc
   « FormDisplay ».
3. **Sélectionner le formulaire** — dans la boîte de dialogue de configuration, sélectionnez le formulaire dans la
   liste de sélection. S’il n’y figure pas (absence de droits d’administration),
   copiez l’adresse du formulaire depuis la barre d’adresse et collez-la dans le champ prévu à cet effet.
4. **Apparence** — si nécessaire, ajustez la couleur d’accentuation, la densité et le
   marquage des champs obligatoires. Les paramètres par défaut sont conformes à l’
   identité visuelle de MAN.
5. **Publier** — enregistrer et publier la page. Pour vérifier,
   utiliser la page publiée : cliquer sur « Envoyer » et la logique « Déjà répondu »
   s'exécute par rapport à l'application de formulaire réelle.
