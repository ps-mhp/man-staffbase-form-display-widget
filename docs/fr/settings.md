# Décors

| Cadre | Description |
| --- | --- |
| Formulaire | Le formulaire à afficher. Champ requis. Généralement via la liste déroulante ; sinon, insérez l’adresse complète du formulaire ou la chaîne de 24 chiffres à la fin. |
| Couleur d’accent | Couleur pour le bouton de soumission, marqueur de champ obligatoire et sélection cochée. MAN rouge par défaut ; alternativement anthracite ou noir. |
| Densité | Standard (hauteur de champ de 40 px) ou Compact (36 px) — pour les pages avec un espace limité. |
| Marqueur de champ obligatoire | Astérisque ('*') ou écrit '(requis)' après l’inscription. |

## Ajouter à la liste restreinte

La liste ne montre que les formulaires pour lesquels vous avez des **droits administratifs**. A
la forme étrangère que vous êtes autorisée à intégrer n’y apparaît pas ; elle
peut toujours être saisie en insérant l’adresse.
