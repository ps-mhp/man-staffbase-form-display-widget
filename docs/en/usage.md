# Step by Step

1. **Create a form** — if you haven’t already: in the
   Staffbase Form app, create and publish the form.
2. **Insert a widget** — on the landing page in the CMS editor, insert the
   “FormDisplay” block.
3. **Select form** — In the configuration dialog, select the form from the
   drop-down list. If it’s not there (no administrative rights), enter the
   form URL from the address bar into the field.
4. **Appearance** — if necessary, customize the accent color, density, and
   required field marking. The default settings comply with the
   MAN CI.
5. **Publish** — Save and publish the page. To test, use the
   published page: Click “Submit,” and the “already answered” logic
   will run against the actual form app.
