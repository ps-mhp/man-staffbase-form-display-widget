# Step by step

1. **Create form** — if you haven't already done so: in the
   Staffbase Forms app, create and publish the form. 
2. **Insert widget** — on the landing page in the CMS editor, select the
   "FormDisplay". 
3. **Select form** — in the configuration dialog, select the form from the
   Select the selection list. If it is missing there (no administrative rights), the
   Form address from the address bar into the field. 
4. **Appearance** — accent color, density, and
   Adjust the required field marking. The default settings correspond to the
   MAN CI. 
5. **Publish** — Save and publish the page. To check the
   Using the published page: Submit and the Already Answered logic
   run against the real form app.
