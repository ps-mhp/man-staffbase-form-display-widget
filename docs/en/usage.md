# Step by Step

1. **Create a form** — if you haven’t already: in the
   Staffbase Forms app, create and publish the form.
2. **Insert widget** — on the landing page in the CMS editor, insert the
   “FormDisplay” block. The “Select Form” window opens automatically;
   later, the “Select Form” button in the
   configuration dialog will open it again.
3. **Select Form** — Click on the form in the list on the left; the search
   field above helps when there are many forms. If it’s not listed there (no
   administrative rights, older than the last 100 modified forms), enter the
   form URL under “Enter ID manually.”
4. **Design** — if needed, select an accent color, density, and required field indicator.
   The default settings comply with the MAN CI. You can preview the result in the respective widths via Desktop, Tablet, and
   Mobile in the header.
5. **Apply** — Click “Apply” in the header (⌘/Ctrl S). This saves
   to the settings dialog; changes are not saved until you click “Save” in Studio.
6. **Publish** — Save and publish the page. To test, use the
   published page: The submit and “already answered” logic
   run against the actual form app.
