# Instellingen

| Setting | Beschrijving |
| --- | --- |
| Formulier | Het formulier dat weergegeven moet worden. Verplicht veld. Meestal via de dropdownlijst; of voeg het volledige formulieradres of de 24-cijferige string aan het einde ervan in. |
| Accentkleur | Kleur voor de verzendknop, verplichte veldmarker en selectievinkje. Standaard MAN rood; alternatieve antraciet of zwart. |
| Dichtheid | Standaard (40 px veldhoogte) of Compact (36 px) — voor pagina's met beperkte ruimte. |
| Verplichte veldmarker | Asterisk ('*') of '(verplicht)' na het label geschreven. |

## Toevoegen aan shortlist

De lijst toont alleen formulieren waarvoor je **administratieve rechten** hebt. A
vreemde vorm die je mag inbedden verschijnt daar niet; het
kan nog steeds worden ingevoerd door het adres in te voeren.
