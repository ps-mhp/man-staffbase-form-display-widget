# Ambientazioni

| Ambientazione | Descrizione |
| --- | --- |
| Modulo | Il modulo da visualizzare. Campo richiesto. Di solito tramite la lista a tendina; in alternativa, inserire l'indirizzo completo del modulo o la stringa di 24 cifre alla fine. |
| Colore d'accento | Colore per il pulsante invia, il campo obbligatorio e il selezionatore di selezione. Impostazione predefinita MAN rosso; alternativamente antracite o nero. |
| Densità | Standard (altezza campo di 40 px) o Compatto (36 px) — per pagine con spazio limitato. |
| Marcatore di campo obbligatorio | Asterisco (*') o scritto '(richiesto)' dopo l'etichetta. |

## Aggiungi alla lista ristretta

L'elenco mostra solo moduli per i quali hai **diritti amministrativi**. A
forma estranea che ti è permesso incorporare non appare lì; esso
può ancora essere inserito inserendo l'indirizzo.
