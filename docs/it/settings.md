# Impostazioni

| Impostazione | Descrizione |
| --- | --- |
| Modulo | Il modulo da visualizzare. Campo obbligatorio. Di norma tramite l'elenco a discesa; in alternativa, inserire l'indirizzo completo del modulo o la stringa di 24 caratteri alla fine dello stesso. |
| Colore di risalto | Colore per il pulsante di invio, l’indicatore dei campi obbligatori e il segno di spunta di selezione. Impostazione predefinita: MAN Rosso; in alternativa, antracite o nero. |
| Densità | Standard (altezza campo 42 px) o Compatta (36 px) — per pagine con poco spazio. |
| Indicatore campo obbligatorio | Asterisco (`*`) o `(required)` scritto per esteso dopo l'etichetta. |

## Vai all’elenco di selezione

L’elenco mostra solo i moduli per i quali si dispone di **diritti di amministrazione**. Un
modulo esterno che si è autorizzati a incorporare non compare quindi in questo elenco; è
comunque possibile inserirlo inserendo l’indirizzo.
